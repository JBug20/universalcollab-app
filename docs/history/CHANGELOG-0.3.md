# 0.3.0
- Dynamic registration using a persistent server join password; case-insensitive username uniqueness.
- Personal persistent tokens, stable OBS keys, and app-managed RTMP(S) destinations.
- Existing users imported without rotating credentials. Old group-based access replaced with explicit approvals.
- Separate directional video/fallback permissions; live revocation.
- Up to two corner feeds plus ordered collaborator fallback choices and reconnect-image fallback.
- Shared masked UI in Firefox, Windows and Linux; platform secure storage in desktop clients.
- Direct IP HTTP compatibility retained, alongside HTTPS support.
- Automatic quiet-period unlock after End retained from 0.2.8.
