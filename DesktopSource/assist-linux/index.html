Pulsoid · Heart-rate actions

Create a personal Pulsoid token with data:heart_rate:read. In OBS, enable Tools → WebSocket Server Settings on this computer.

Rules start stopped. A fresh reading must reach the reset side before a rule can fire. Above rules reset below the threshold; Below rules reset above it. Only the first matching scene change runs when multiple rules fire together.
